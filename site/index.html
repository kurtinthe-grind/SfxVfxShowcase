        How this works

        The mod's QR CODE button does not put asset names in the code. It puts short IDs, three characters each, for example 0XG for FX_ArtilleryStrike_Explosion_01. This page has the public table that turns the IDs back into names. That keeps the codes small enough to scan from across the room.

        An ID never changes meaning, so a code you made months ago still reads the same. The IDs are labels, not encryption: anyone can look them up here or in the registry. Nothing you scan or paste leaves your browser.

        Older codes that hold full names still work.
